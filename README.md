<p>I build payment, trading and transaction systems in TypeScript and Node.js, and run them in production on Docker, Kubernetes, AWS and Cloudflare. Most of it shipped in Web3, where correctness moves real money.</p>

- 💳 Built a merchant payment gateway that settles in under 60 seconds with exact amounts across 10 networks
- 📈 Architecting **Vistapex**, a prediction-market trading platform with real-time feeds and copy trading
- 🚀 Worked on AWS, Hetzner and Cloudflare (k3s, GitHub Actions, Prometheus, Grafana)
- 🤝 Open to backend, DevOps and select Web3 roles in payments and infrastructure

<h3>Projects</h3>

| Project | What it is | Stack |
| --- | --- | --- |
| [**Xyra Payment Gateway**](https://xyra.trade/swap) | Merchant payment gateway, live in production. Settles in under 60 seconds with exact amounts across 10 networks, with QR deposits and per-user deposit addresses. | TypeScript · Node.js · Webhooks |
| [**Vistapex**](https://www.vistapex.trade) | Prediction-market trading platform on Avalanche. Market resolution service, per-user WebSocket feed, copy trading with risk limits, k3s deploys with automatic rollback. | TypeScript · WebSockets · k3s |
| [**Trade-Routing API**](https://xyra.trade/swap) | Order-splitting engine across 10+ liquidity venues, with a Redis cache layer, worker-thread quote pool, API keys and rate limiting. | TypeScript · Redis · Worker threads |
| [**EthosX OPerps**](https://operps.ethosx.finance) | Perpetual options trading platform: trade execution backend, React frontend and Solidity integration on Arbitrum and BSC. | Node.js · React · Solidity |
| [**OBLIQ**](https://github.com/gunaseelan25/OBLIQ) | Open-source gasless SDK for Solana: 1-click onboarding, sponsored transactions and USDC gas payments. [Demo →](https://obliq-demo.vercel.app) | TypeScript · Solana |
| [**Sui Liquid Staking**](https://blog.sui.io/liquid-staking-hackathon-winners) | Liquid staking primitive for Sui. Shortlisted by the Sui Foundation. | Sui Move · TypeScript · React |
